Preview Open Graph (1200×630) — abre no Chrome, screenshot na proporção exata, exporta como PNG

Como converter pra PNG (necessário pra OG real — Meta/LinkedIn não renderizam SVG):
1. Abra este HTML no Chrome/Firefox em monitor que comporte 1200px.
2. DevTools (F12) → device toolbar → set viewport 1200×630 → screenshot.
3. Alternativa: chromium --headless --screenshot=og-image.png --window-size=1200,630 og-image.svg
4. Alternativa online: cloudconvert.com/svg-to-png (input SVG 1200×630).
Output esperado: PNG ≤ 200 KB. Salvar como og-image.png na mesma pasta.
